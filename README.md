# EMBODI

**Embodied Multi-agent Orchestration for Domain Intelligence**

A multi-domain pipeline for embodied agentic AI, developed at the PLOT Initiative
(Kennesaw State University). EMBODI runs across rooms and application domains
on a shared multimodal data substrate, with a learned routing layer that decides
when to reason on-device and when to escalate to the cloud.

> **Status: pre-release.** Full source, documentation, and the PLOT-Bench
> dataset will be released here under Apache-2.0 (code) and CC-BY 4.0 (data)
> upon publication of the accompanying papers.

---

## What this is

Embodied AI agents for assistive, environmental, agricultural, and human-wellness
applications, built on the same procedural pipeline (acquire, synchronize, fuse,
infer, reason). Designed to run on edge-class hardware and to scale through
controlled cloud reasoning when complexity warrants it.

## What this is not (yet)

A public reference implementation. We are finalizing the framework, the
capability-event schema, and the dataset cards before release.
